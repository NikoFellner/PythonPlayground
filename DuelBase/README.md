## ⚔️ Turn-Based Battle Simulator

A console-based turn-based combat game written in pure Python.
The goal of this project is to improve Python fundamentals by building a structured, expandable battle system step by step.

## 🎯 Project Goal

Create a playable battle simulator where:
 - A player fights an AI opponent
 - Each character takes turns
 - Players can choose different actions
 - The battle ends when one character reaches 0 HP
 - The project is divided into small development phases to encourage incremental learning and clean architecture.

## 🟢 Phase 1 – Minimal Playable Version (MVP)

Objective: Make the game playable as fast as possible.

Tasks
- Create a Character class
- Add attributes: name, health (HP), attack power
- Implement a basic attack method
- Create a simple game loop
- Alternate turns between player and AI
- End the game when one character’s HP reaches 0
- Display battle messages in the console


## 🟡 Phase 2 – Add Combat Depth

Objective: Make combat more interesting.

Tasks
- Add a special attack ability
- Add a heal ability
- Implement simple AI decision-making logic
- Add critical hit chance
- Improve input validation
- Display current HP after each turn


## 🔵 Phase 3 – Character Classes & Abilities

Objective: Introduce variety and better architecture.

Tasks
 - Create multiple character types (e.g., Warrior, Mage, Rogue)
 - Implement different stats per class
 - Add ability cooldown system
 - Implement status effects (poison, stun, burn)
 - Create a battle log system


## 🟣 Phase 4 – Advanced Features (Optional)

Objective: Turn the simulator into a small game system.

Tasks:
 - Add experience points (XP)
 - Implement leveling system 
 - Add multiple enemies 
 - Implement turn order based on speed stat 
 - Add save/load functionality 
 - Create simple ASCII UI improvements
